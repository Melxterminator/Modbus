# 🔌 Estudos de Comunicação Modbus

Este repositório é dedicado aos meus **estudos sobre o protocolo de comunicação Modbus**, com foco na aplicação em **automação industrial, instrumentação e manutenção**.

A proposta é utilizar este espaço para registrar conceitos, testes, exemplos práticos, configurações e aprendizados relacionados à comunicação entre **PLCs, instrumentos, sensores, inversores, IHMs e outros dispositivos industriais**.

## 🎯 Objetivo

O objetivo deste repositório é compreender como o **Modbus** funciona na prática, desde seus conceitos fundamentais até a comunicação entre diferentes dispositivos industriais.

Os estudos serão desenvolvidos relacionando:

**teoria → configuração → comunicação → diagnóstico → aplicação prática**

## 🏭 Modbus na Instrumentação Industrial

Como parte dos meus estudos está relacionada à **Instrumentação Industrial**, o foco também será compreender como o Modbus pode ser utilizado para comunicação com instrumentos de campo.

Exemplos de aplicações:

* Transmissores de pressão;
* Transmissores de temperatura;
* Transmissores de nível;
* Medidores de vazão;
* Inversores de frequência;
* Controladores;
* CLPs;
* IHMs;
* Sensores e outros dispositivos industriais.

A ideia é compreender o caminho completo da informação:

```text
Instrumento
    ↓
Comunicação Modbus
    ↓
PLC / Controlador
    ↓
Lógica de controle
    ↓
Atuador / Processo
```

## 🔧 Modbus na manutenção

Além da programação e configuração, os estudos terão foco no **diagnóstico de problemas de comunicação**.

Algumas situações que poderão ser estudadas:

* Dispositivo não responde;
* Endereço incorreto;
* Baud Rate incompatível;
* Paridade incorreta;
* Problemas de cabeamento;
* Inversão de linhas A/B no RS-485;
* Falha de aterramento;
* Conflito de endereços;
* Registrador configurado incorretamente;
* Dados recebidos com valores inesperados;
* Erros de CRC;
* Problemas de configuração entre dispositivos.
